# 우리 태양계

6살 아이 눈높이에 맞춘 태양계·우리은하 탐험 웹 앱입니다. 태블릿 전체 화면에서 행성을 누르면, 짧은 한글 설명과 읽어 주기 소리를 들을 수 있습니다. 상상의 행성도 직접 만들 수 있어요. 인터넷이 없어도 동작하고, 탐험 도장과 만든 행성은 이 기기 브라우저에만 저장됩니다.

온라인 주소: https://blackhun1986.github.io/space/

## 쓰는 방법

1. 위 주소를 태블릿(또는 컴퓨터) 브라우저로 엽니다.
2. 브라우저 메뉴의 **홈 화면에 추가** / **앱 설치**를 누르면 전체 화면 앱처럼 쓸 수 있습니다.
3. 행성과 태양, 달, 우리은하를 눌러 이야기를 듣고, 퀴즈로 복습할 수 있습니다.
4. **행성 만들기**를 눌러 나만의 상상 행성을 만들고, 이름과 탐험가 사진도 남길 수 있습니다.

같은 폴더에서 `python3 -m http.server 8080` 으로 열어도 됩니다.

## 무엇이 있나요

- 태양, 수성, 금성, 지구, 달, 화성, 목성, 토성, 천왕성, 해왕성, 명왕성(왜소행성), 우리은하
- 행성을 누르면 쉬운 설명, 재미있는 사실, 온도, 로켓으로 가는 대략적인 시간이 나와요
- **읽어 줘** 버튼을 누르면 한국어로 들려줘요 (이모티콘은 읽지 않아요)
- 처음 탐험한 곳마다 도장을 모아요
- 간단한 퀴즈
- **나만의 행성 만들기**: 행성마다 이름과 사진을 남기고, 색깔, 크기, 무늬, 고리, 달 개수(0~3개), 얼굴, 날씨, 누가 사는지를 고를 수 있어요. 만든 행성은 최대 6개까지 저장되고, '내가 만든 상상 행성'이라고 분명히 표시돼요.

## 개인정보

탐험 기록, 만든 행성, 행성 이름, 탐험가 사진은 모두 이 기기 브라우저의 `localStorage`에만 저장됩니다. 외부 서버로 전송되지 않습니다.
