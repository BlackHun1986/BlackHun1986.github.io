# 참 잘했어요!

집에서 쓰는 아이 할 일 · 스티커 웹 앱입니다. 태블릿 브라우저에 맞춰 큰 버튼과 한글 화면으로 만들었습니다. 인터넷이 없어도 동작하고, 데이터는 이 기기의 브라우저에만 저장됩니다.

## 쓰는 방법

1. 이 폴더 안의 `index.html`을 태블릿(또는 컴퓨터) 브라우저로 엽니다.
2. 홈 화면에 추가하거나 오프라인 저장을 쓰려면, 가능하면 간단한 웹 서버로 여는 것이 좋습니다.
   - 예: 이 폴더에서 `python3 -m http.server 8080`
   - 같은 Wi-Fi에 있는 태블릿 브라우저에서 `http://(컴퓨터주소):8080` 으로 접속합니다.
3. 브라우저 메뉴의 **홈 화면에 추가** / **앱 설치**를 누르면 전체 화면 앱처럼 쓸 수 있습니다.

`file://`로 바로 열어도 사용은 가능하지만, 카메라·홈 화면 추가·오프라인 캐시는 브라우저에 따라 제한될 수 있습니다.

## 처음 설정

1. 아이 수(1~6명)를 고릅니다.
2. 각 아이의 이름과 성별(남/여)을 입력합니다.
3. 안내를 따라 얼굴 사진을 찍거나 고릅니다. 건너뛰어도 됩니다.
4. 오늘 할 일을 체크하고, 목표 개수(기본 7개) 이상 하면 스티커를 받습니다.
   - 남자 아이: 별 스티커
   - 여자 아이: 하트 스티커
   - 하루에 스티커는 한 개입니다. 할 일 체크는 매일 자정(기기 날짜) 기준으로 새로 시작되고, 모은 스티커는 그대로 남습니다.

## 설정

홈 화면의 톱니바퀴를 누르면 부모님 확인(간단한 덧셈) 후에 설정으로 들어갑니다.

- 할 일 목록 추가·삭제·순서 바꾸기 (공통 목록 또는 아이별 목록)
- 스티커를 받는 데 필요한 할 일 개수
- 아이 이름·성별·사진 수정, 아이 추가·삭제
- 모든 데이터 초기화

## 개인정보

사진과 이름, 할 일, 스티커는 모두 이 기기 브라우저의 `localStorage`에만 저장됩니다. 외부 서버로 전송되지 않습니다.
