# 공룡 탐험 (6살 전용)

지구에서 시작해서 공룡 시대(트라이아스기·쥐라기·백악기)로 떠나는 6살용 학습 웹앱이에요.
삼성 갤럭시 탭 같은 태블릿 브라우저에서 잘 보이게 만들었고, 한 번 열어 두면 인터넷이 없어도 돼요(PWA).

## 쓰는 방법
- 첫 화면의 지구는 가운데에서 120도로 세 조각(트라이아스기·쥐라기·백악기)으로 나뉘고, 조각이나 그 시대 공룡을 누르면 그 시대 풍경으로 들어가요.
- 풍경 속 공룡을 누르면 이름·크기·먹이·특징·"쉿! 나만 아는 비밀"이 나오고 "읽어 줘"로 읽어 줘요.
- 풍경 왼쪽 위 "지구" 버튼으로 돌아와요. "퀴즈"는 5문제예요.
- 만난 공룡은 ⭐로 표시돼요(이 기기 브라우저에 저장).

## 파일
- `index.html`, `styles.css`, `app.js` – 화면과 동작
- `data.js` – 시대와 공룡 30마리의 설명, 퀴즈
- `art.js`, `assets/dinos/` – 공룡 30마리의 반사실적인 그림(투명 배경 WebP)
- `scenes.js` – 시대별 배경 그림
- `sw.js`, `manifest.json`, `icons/`, `fonts/` – 오프라인 앱(범위 `/dino/`), 아이콘, 글꼴(Jua, Gothic A1)

## 실행
`./serve.sh` 로 로컬 서버(`http://127.0.0.1:8933`)를 열거나 `python3 -m http.server`.
테스트: `npm i puppeteer-core` 후 `node test.js`(크롬 필요).

배포: GitHub Pages의 `/dino/` 폴더에 위 앱 파일만 복사해요.
